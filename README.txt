BETWEEN BLANKS — RESPONSIVE BAND WEBSITE

Files:
- index.html
- style.css
- script.js

Everything is static HTML/CSS/JavaScript and can be deployed directly to GitHub Pages.

PLACEHOLDERS:
The site deliberately uses CSS placeholder artwork/photo/video areas so no copyrighted stock media is bundled.
Replace each .placeholder-art / .placeholder-photo / .placeholder-video area with your own assets later.

Suggested asset structure:
assets/images/hero.jpg
assets/images/album.jpg
assets/images/band-1.jpg ... band-4.jpg
assets/images/merch-1.jpg ... merch-3.jpg
assets/videos/cage-of-desperation.mp4

For YouTube videos, replace the placeholder video cards with YouTube embeds or links.
